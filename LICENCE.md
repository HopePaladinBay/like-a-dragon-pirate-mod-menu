## 🧩 About

**Like a Dragon Pirate Yakuza helpers** is a curated list of Like a Dragon Pirate Yakuza open-source tools:

- **Overlays** — on-screen helpers, layout notes, HUD customization, minimap tweaks
- **Quality-of-Life Helpers** — inventory manager, fishing assistant, crew management notes
- **Research Notes** — combat timings, sailing routes, and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### 🎮 Gameplay Helpers
- Infinite Health — toggle invincibility for practice
- Infinite Stamina — remove fatigue during exploration
- One-Hit Stun — adjust enemy stun duration for study
- Stealth Mode — avoid random encounters for route planning
- Time Scale — slow down or speed up game time for analysis

### ⚙️ Inventory & Resources
- Item Spawner — add any item to inventory for testing
- Money Editor — set currency amount for research
- Resource Multiplier — adjust loot and material gains
- Equipment catalog — access all gear for build testing
- Cooking Helper — unlock all recipes and ingredients

### 🗺️ Navigation & Map
- Teleport to Waypoint — fast travel to custom markers
- Reveal Map — uncover all map areas for study
- Waypoint Manager — save and load custom locations
- Minimap Overlay — enhanced minimap with points of interest
- Sailing Speed — adjust ship speed for faster travel

### 🎨 Visual & UI
- HUD Editor — customise on-screen elements
- FPS Counter — monitor performance
- No Clip — free camera for exploration (educational)
- Weather Control — set time of day and weather
